# Bun client build (replaces webpack)

Date: 2026-08-10

## Intent

Compile `src/js` → **`dist/js/`** (gitignored) with Bun, not webpack. Chart SCSS → **`dist/css/chart.css`**.

Thalia serves `dist` before `public`. Do **not** commit hashed `chunk-*` files.

## Commands

```bash
bun run build          # production minify → dist/
bun run build:dev      # readable + sourcemaps → dist/
bun run develop:client # watch → dist/
bun run preview        # build:dev + NODE_ENV=production thalia  (serves dist JS)
```

`bun run dev` (`thalia-develop`) uses `node_env=development`, which **skips** `dist/*.js` and `dist/*.css` so on-demand compile can run. For this site’s bundles, use **`bun run preview`** (or `NODE_ENV=production thalia` after a build).

Operator: after editing `package.json`, run `bun install` so removed webpack/babel loaders drop out of the lockfile.

## Layout

| Path | Commit? | Role |
|------|---------|------|
| `src/js/`, `src/css/chart.scss` | yes | Source |
| `dist/js/`, `dist/css/chart.css` | **no** (`dist` in `.gitignore`) | Bun / sass output |
| `public/js/*vendor*` / `*.min.js` | yes | Hand-dropped vendors (`assets.mustache`) |
| `public/dataviz/*` | yes | CSV, geojson, images |

Each build **scrubs** generated entry/chunk/wasm leftovers out of `public/js` so they are not re-committed. Vendors stay.

## What the script does

`scripts/build-client.ts`:

1. Wipe + rebuild `dist/js` for all `src/js/**/*.ts` (skip `*.d.ts`, `*.test.ts`) with ESM + splitting.
2. Copy Rapier `*.wasm` into `dist/js/` and rewrite `new URL("….wasm", "<deleted>")` → `import.meta.url`.
3. Compile `src/css/chart.scss` → `dist/css/chart.css`.
4. Scrub matching generated files from `public/js`.

Pages still request `/js/chart.js` and `/js/{shortname}.js` (`require.hbs`) — satisfied from `dist` in production.

## Known deltas vs webpack

| Webpack | Bun |
|---------|-----|
| `public/js` (prod) / `dist/js` (dev mode in old config) | Always **`dist/js`** (gitignored) |
| `ProvidePlugin` | Chart re-exports + `assets.mustache` vendors |
| Hashed wasm | Stable `rapier_wasm{2,3}d_bg.wasm` in `dist/js` |
| Three aliases | Explicit `.js` imports on OBJ/MTL loaders |
